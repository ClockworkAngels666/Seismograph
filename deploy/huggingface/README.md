# Seismographic

*Picking up political tremors before they become earthquakes.*

A transparent country risk index built from open data (World Bank, IMF, UNHCR, UCDP), with a 3D globe, risk
history since 2015, live news and video, and a guide to what the numbers mean in real life.

Built by Tuan Dung Nguyen.
