# Case-study commentary

The *Did it see it coming?* page shows, for each case, what the index said the year before the event. Add your
own analysis by creating a Markdown file here named after the case. It appears under the data as
**Analyst commentary**.

| Case | File name |
|---|---|
| Ethiopia: war in Tigray (2020) | `ethiopia-2020.md` |
| Myanmar: military coup (2021) | `myanmar-2021.md` |
| Afghanistan: Taliban takeover (2021) | `afghanistan-2021.md` |
| Ukraine: full-scale Russian invasion (2022) | `ukraine-2022.md` |
| Sri Lanka: default and mass protests (2022) | `sri-lanka-2022.md` |
| Sudan: civil war (2023) | `sudan-2023.md` |
| Niger: military coup (2023) | `niger-2023.md` |
| Bangladesh: student-led uprising (2024) | `bangladesh-2024.md` |

Good commentary answers three questions in a few short paragraphs:

1. **What did the data get right?** Which pillar or red flag pointed the right way, and how early?
2. **What did it miss, and why?** For example a coup inside the security forces, an outside invasion, or a crisis
   that the yearly data could not see coming.
3. **What would an analyst have watched?** The signposts that, with hindsight, mattered most.
